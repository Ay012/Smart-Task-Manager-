# Project Statement

## Project Title

**Smart Task Manager**

## Problem Statement

Managing daily tasks using paper-based notes or scattered applications can make it difficult to keep track of pending and completed work. Users need a simple and efficient way to organize their tasks and update their status whenever required.

The **Smart Task Manager** is a command-line application developed in Java to provide a simple solution for managing daily tasks. The application allows users to add new tasks, view existing tasks, mark tasks as completed, and delete tasks through a menu-driven interface. Tasks can also be stored in a file so that they can be retained between program executions.

## Objective

The primary objective of this project is to develop a lightweight task management system using core Java programming concepts. The project aims to:

* Provide a simple command-line interface for managing tasks.
* Allow users to create, view, complete, and delete tasks.
* Demonstrate Object-Oriented Programming concepts in Java.
* Use Java collections such as `ArrayList` for task management.
* Implement persistent storage using file handling.
* Apply Java programming concepts to a practical real-world problem.

## Scope

The current project focuses on basic task management through a command-line interface. Users can create and manage tasks while keeping track of their completion status.

The project can be extended in the future by adding features such as:

* Task deadlines and priorities
* Task searching and filtering
* Improved file or database storage
* User accounts and authentication
* Graphical
